Widgets are a second, smaller surface. Glance gives you boxes, rows, columns, text and images, no custom drawing and no fonts of your own — so the Editions look here comes from colour, spacing, the plate rule and a numeral-free layout. Archivo is not available in a widget; Readex Pro is not either. What survives is the bone, the ink, the square photograph and the clay name.

Motion is one table: every animated moment in the app, its duration, easing, what it does under reduced motion, and whether the phone should be felt. Four durations, three eases, five haptic levels. Anything not in the table does not animate.

The build order confirms the brief's §10 with two adjustments: the dock moves up (it is the mobile-only journey and it is what the trip screen is built around), and the invite screen ships before settings because it is the growth loop and has no dependency on the kit beyond Button, Stamp and Avatar.

Glance constraints honoured

No custom fonts: text uses the system font at 13 / 12.5 / 11 sp, weights 400 / 600 / 700 via FontWeight. No numerals, no Stamp, no italic clay phrase. Colours from GlanceTheme.colors only; the clay actor span uses onTertiaryContainer; unseen rows use tertiaryContainer. Skeleton: none — Glance shows the last render until the new one lands; first render shows a surfaceVariant plate with the trip title. Error / offline: last good render stays; if none, "Open Thykra to pick a trip". Update cadence: WorkManager periodic 30 min + on app foreground + on upload batch complete.

Taps · accessibility

Every plate → thykra://album/{id}/media/{mediaId}; caption and header → thykra://album/{id}; activity row → its first media. "Open trip →" is a Button composable so it is a real accessible target. Content descriptions: plate "Latest photo in Wadi Rum, by Sara", rows read their sentence. Text scales with system font size; the 2×2 caption drops the actor line above 1.3× and the 4×2 drops the counts. RTL: Glance mirrors Rows; thumbnails stay square, "Open trip →" becomes "← افتح الرحلة" from the string table (the arrow is a character, so it flips with the string).

Motion and haptics

Tokens from Part 1: dur1 120 · dur2 200 · dur3 320 · dur4 520 ms; easeOut (.2,.8,.28,1) · easeInOut (.5,0,.3,1) · spring (.2,1.25,.3,1) — authored cubic, not physical; stagger 40 ms capped at 8. Haptics through one expect fun haptic(kind: HapticKind): Tick (Android CLOCK_TICK / iOS selection), Confirm (CONFIRM / .success), Reject (REJECT / .error), LongPress (LONG_PRESS / .medium), None. Haptics never fire for anything the user did not just touch, and never more than once per gesture.

Reduced motion, as one rule

LocalReducedMotion is read once at the theme root. When true: every tween whose target is a transform (offset, scale, rotation) becomes a dur1 alpha fade; scroll-driven and gesture-driven motion stays because the user is driving it; indeterminate sweeps become alpha pulses; nothing auto-advances; stagger is 0. Implement as a Modifier.thykraAnimate() wrapper and a thykraTween() factory so screens never branch on the flag themselves.

Haptics, the whole list

Tick: segmented and theme taps, picker open, selection toggles, predictive-back commit, zoom bounds. Confirm: reaction pick, batch celebration, joined. Reject: destructive confirm, reaction rollback, first failed upload in a batch, error toasts. LongPress: entering selection mode. Everything else: none — including button taps, tab switches, sheet opens and every scroll. A setting to turn haptics off is not offered in v1; the system-wide toggle governs.

Performance guards

No blur anywhere (the viewer gradients are flat alpha). Shared-element transitions use SharedTransitionLayout with the plate's Modifier.sharedBounds keyed "media/{id}"; the pager's off-screen pages do not participate. Reaction burst copies are three Texts in a Box, not particles. Stagger is capped at 8 items so a 40-plate chapter never queues 1.6 s of entrances. All grid images use Coil's crossfade(dur2) and nothing else.

iOS parity

Every row above runs on iOS through Skia unchanged, except: predictive back becomes the platform interactive pop (UIKit handles it; the Compose screen just fades), haptics map to UIImpactFeedbackGenerator / UINotificationFeedbackGenerator in iosMain, and reduced motion reads UIAccessibility.isReduceMotionEnabled. Nothing in the table is Android-only.

Build order — §10 confirmed, two moves

Twelve steps, each a sub-issue under THY-166, each shippable with the old screens still in place. Changes from the brief: the upload dock moves from step 10 to step 6 because the trip screen (step 5) is designed around it and building the trip without the dock means building the action bar twice; invite preview moves ahead of settings because it depends only on Button, Stamp and Avatar and it is the growth loop. Everything else holds.

Bundle the three font files; ThykraTheme with both schemes, ExtendedColors, typography (default, compact, Arabic), shapes, motion locals, reduced-motion expect/actual; theme preference in DataStore read synchronously; the viewer's forceDark. Add --bad-text / --good-text / --warn-text to tokens.css in the same PR. Done when: every old screen renders under the new theme in both modes with no literal colour left in ui/.

Acceptance, repeated on every step

Both themes · 393 and 360 widths · 100% and 200% font scale · TalkBack pass on the new screen · reduced motion on · airplane mode: no blank screen · no literal colour, size or duration outside ui/theme/ and ui/kit/ (lint rule in the first PR) · iOS build compiles and the screen renders in the iOS simulator even if unpolished.
