Thykra mobile · Compose MultiplatformPart 2 of 4Deliverable 3 — component kit and icon set

Thirty icons,
twenty parts.

Every component below is a Material 3 composable with its defaults overridden once, in ui/kit/, and never again in a screen. Screens compose kit parts; they do not restyle them. Each part is shown in Paper and Darkroom with every state it has, and carries the Kotlin signature a developer types first.

Sizes are dp, type is the theme slot from Part 1, colours are role names. Where a component needs a colour Material has no slot for, it reads MaterialTheme.thykra. A hex in a screen file is still a review failure.

The icon set is exactly 30 hand-drawn paths at 24 dp, 1.75 dp stroke, round caps. Destructive verbs (delete, remove, block, leave, sign out) are always text labels, never icons, which is why the set has no bin and no door.

Component kit

Reading a card: Paper on the left, Darkroom on the right, every state the part can be in, then the spec strip — signature, anatomy in dp, roles, behaviour, TalkBack. Interaction states follow one rule kit-wide: pressed = container swaps to its *Pressed colour (or 8% onSurface overlay for surfaces) with Material's ripple on top; focused (keyboard, TV, Switch Access) = 2 dp primary ring at 2 dp offset, never a fill change; disabled = 38% alpha on content, container unchanged, no elevation.

Avatar

Circle. Photo via Coil with crossfade(dur2); fallback fill = thykra.avatarTints[userId.hashCode() mod 5], initials from User.name (first letter of first two words; one letter for single-word names) in onTertiary, weight 600, size ≈ 0.4 × diameter. Double rule: 2 dp border, 1 dp second ring at 2 dp offset, radius 4. Padding 8 × 14. Eyebrow labelSmall, name headlineSmall at 16 sp. Rotation −3° LTR, +3° RTL, applied with graphicsLayer so layout bounds stay square. Colour tertiary; warning when the invite is expired. Allowed surfaces: invite preview, share sheet, public Recap header. Never two on one screen.

Sheets never stack: a sheet that needs a dialog closes first, then the dialog opens.

Dialog

The only AlertDialog in the app. Container surfaceContainerHigh, shape large, width = window − 48 capped at 312, scrim thykra.scrimStrong. Title headlineMedium phrased as a question naming the thing; body bodyMedium stating the consequence in numbers from the DTO. Confirm = filled error/onError with the verb + noun; cancel = Text. Not dismissable by scrim tap; back cancels. Confirm shows loading, then closes and Toasts.

Toast

Replaces Material's inverse Snackbar. Container surfaceContainer, shape medium, level3, 3 dp leading bar in primary / success / error. Text bodySmall, action labelLarge at 14 sp in onPrimaryContainer. Sits 12 dp above the bottom chrome (nav bar, action bar or dock — whichever is topmost). Duration 4 s, 8 s with an action, indefinite with Retry while offline. One at a time; a new one replaces.

TalkBack

Dialog traps focus, reads title then body, confirm button last so a swipe-through hears the consequence before the verb. Toast is a liveRegion = Polite; error toasts are Assertive. Undo toasts extend to 10 s when TalkBack is on.

Skeleton

Modifier.skeleton(shape): fill surfaceVariant, one sweep of surface at 60% travelling start→end every 1400 ms, easeInOut. Reduced motion: no sweep, alpha pulses 1 → .7 at 1400 ms. Skeletons copy the real layout — a chapter skeleton has a numeral-shaped block, a 2 dp rule and a 2-column grid — so the swap to content moves nothing. Shown after 200 ms of loading (never flash), replaced with a dur2 cross-fade. Spinners exist only inside buttons and the dock.

EmptyState
EmptyState(headline: AnnotatedString,
  body: String, glyph: EmptyGlyph,
  primary: ThykraButtonSpec?,
  secondary: ThykraButtonSpec? = null)

Glyph is one of three drawn shapes (empty plate, dashed person circle, Offline icon at 24 dp) — no illustration. Headline displayMedium with one clay italic word; body bodyLarge. Vertical padding 32, centred, max width 320.

Copy for each empty

Trips: "No trips yet." / "Start one and invite the people who were there." · Trip: "Nothing here yet." · Activity: "Quiet, for now." / "When friends add, react or comment, it shows here." · Recaps: "Twelve photos first." / "Recaps build from trips with 12 or more photos." · Members-only: "Just you, so far." · Error: "Something slipped." / "We couldn't load this. Try again in a moment."

Offline banner

Distinct from the empty: a 40 dp strip under the top bar, warningContainer/onWarningContainer, Offline icon + "You're offline · showing saved trips", bodySmall. Slides in dur3, out when connectivity returns. Cached content stays interactive beneath it; actions that need the network Toast with Retry instead of disabling.

Signature · data
UploadDock(batch: UploadBatch,
  expanded: Boolean, onToggle,
  onRetry(fileId), onRetryAll,
  onSeeThem, showTripName = false)

Reads UploadQueueManager only: per-file UploadState (QUEUED · UPLOADING(bytes,total) · CONFIRMING · DONE · FAILED(attempt)), the connectivity flag, and the batch id. Batch = every file enqueued for one trip within 60 s of the last. Time-left is a 10-sample moving average of bytes/s, shown only after 3 s and once under 1 h, rounded to minutes.

Anatomy

Container surfaceContainer, shape medium, level3, 16 dp side margins, pinned 8 dp above the action bar (trip) or nav bar (trips list). Collapsed 76 dp: 40 dp thumbnail of the file in flight · titleMedium summary · labelMedium detail · Chevron · 4 dp track in primaryContainer, fill primary (warning while offline). Expanded adds a row list capped at 40% of window height, scrollable, failed rows first, then active, queued, done.

Row states

48 dp: 36 dp thumb (Video badge at 12 dp for video) · filename bodySmall · status at end · 3 dp track. Uploading determinate from bytes, "62%". Queued empty track, "Queued". Confirming indeterminate sweep, label in warning — the only indeterminate state besides Queued-while-offline. Done Check in success, row at 70% and dropped to the end. Failed errorContainer full-bleed row, Alert + "Didn't send", 40 dp Retry icon button; "Retry all" appears in the header when ≥ 1 failed.

Lifecycle · celebration

Appears dur3 slide-up when the first file enqueues. When every file is DONE the dock flips to successContainer: "43 photos are in." · "Sorted into N days" (N from the new chapters) · See them scrolls to the first new plate. Auto-dismisses after 6 s, or on See them. One celebration per trip per batch; failures keep the dock up indefinitely with Retry all. Survives navigation — it is hosted by the Scaffold, not the screen — and re-mounts on cold start from the persisted queue. TalkBack: the header is one node with liveRegion = Polite announcing count changes at most every 10 s; rows read "filename, 62 percent" or "filename, didn't send, Retry button".

A Popup anchored above the React button (or above the long-pressed plate), not a sheet — it must be one thumb-move away. Cells stagger in 40 ms, scale .6 → 1 with spring; the picked emoji bursts (Part 4). Dismiss on pick, outside tap, back.

Chip: "Fire, 4, you reacted" / "Fire, 4" with role = Checkbox. Picker cells read the reaction's English name from a string table (the emoji glyph is never the label). Haptic Tick on picker open, Confirm on pick — the only two haptics tied to reactions.
